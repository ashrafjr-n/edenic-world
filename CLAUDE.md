# Edenic World — Project Facts

Kids' entertainment/edu-tech site for the "Edenic World" brand (characters: Nova, Bloo, Pinki). Content is English-only; the site UI targets English, Arabic, and Kurdish audiences (Kurdish is the primary UI language for now). Building the MVP first: one Learn path (staged lessons) linked to one Play game, to prove the Entertainment → Learning → Play loop, before the client approves further scope.

## Stack (installed so far)

- Next.js 16 (App Router, Turbopack, TypeScript, `src/` dir, `@/*` import alias) + Tailwind CSS v4.
- Prisma 7 ORM, PostgreSQL provider. Client generator output: `src/generated/prisma` (gitignored, run `npx prisma generate` after pulling if missing). `DATABASE_URL` lives in `.env` (gitignored) — currently a placeholder, no real database is provisioned yet.
- Phaser (game engine) installed for the Play section; not wired into any page yet.

Nothing else is installed yet on purpose (no Framer Motion, GSAP, Howler, Zod, React Hook Form, TanStack Query, Sentry). Add libraries only when a specific step actually needs them, and mention it explicitly per vibe.md's rule.

## Commands

- `npm run dev` — starts the app at http://localhost:3000. No database needs to be running for this to work as long as no code path queries Prisma yet.
- `npx prisma generate` — regenerate the Prisma client after editing `prisma/schema.prisma`.
- `npx prisma migrate dev` — apply schema changes to a real database (needs a working `DATABASE_URL` first).

## Structure

- `src/app/` — Next.js App Router pages/routes.
- `prisma/schema.prisma` — data model.
- `.agents/skills/`, `.claude/skills/` — Prisma-provided reference skills for using Prisma 7 correctly (auto-generated by `prisma init`, kept as-is).
